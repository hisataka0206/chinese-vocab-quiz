## 3. [[最重点パターン]] の詳細

### パターン α: [[2-1]] (50%失敗 / Lift 2.9×)

| 単語 | Pinyin |
|---|---|
| 直播 | zhi(2) bo(1) |
| 衔接 | xian(2) jie(1) |
| 提高 | ti(2) gao(1) |
| 航天 | hang(2) tian(1) |
| 核心 | he(2) xin(1) |
| 龙头公司 | lóngtóu gōngsī |

**原因仮説**: 1音節目の **2声がトップまで上がりきる前** に 2音節目の 1声 (高平調) に遷移するため、2声が「中の中」で止まる → 聞き手には「3声→1声」or「軽声→1声」と誤認される。

**矯正のコツ**: 2声単音節を「思っているより 1段階高く」まで上げ切ってから 1声に入る。語末の 1声は **始点を 2声の終点と同じ高さ** で揃える。

### パターン β: [[1-3]] (40%失敗 / Lift 2.4×)

| 単語 | Pinyin |
|---|---|
| 缩短 | suo(1) duan(3) |
| 编程 | bian(1) cheng(3) |
| 风险 | feng(1) xian(3) |
| 分拣 | fen(1) jian(3) |
| 污染 | wu(1) ran(3) |
| 抓取 | zhuā qǔ |

**原因仮説**: 1声 (高平調) のあとに 3声 (低い下降-上昇) へ落とすが、**3声の谷の底まで下がりきらず** 高めのまま終わる → 「1-1」または「1-軽声」に聞こえる。先生フィードバックの「4声(と3声)が下がり切らない」現象がここでも発生。

**矯正のコツ**: 1声は中の高 (5)、3声は底まで (2→1→2)。3声の「いったんしっかり下げる」感覚を体に入れる。録音して波形を見るのが効果的。

### パターン γ: [[3-3]] (33%失敗 / Lift 2.0×)

| 単語 | Pinyin |
|---|---|
| 扭矩 | niu(3) ju(3) |
| 主板 | zhu(3) ban(3) |

サンプルは少ないが、**三声変調 (3-3 → 2-3 ルール)** が崩れている可能性。先生指摘の3声は撤回された経緯があるが、3-3 連続は別問題として残る。

### パターン δ: [[4-1]] (25%失敗 / Lift 1.5×)

| 単語 | Pinyin |
|---|---|
| 聚焦 | ju(4) jiao(1) |
| 滞销 | zhi(4) xiao(1) |
| 订单 | ding(4) dan(1) |
| 弹夹 | dan(4) jia(1) |
| 化工 | hua(4) gong(1) |

**原因仮説**: 4声で **下まで落とし切る前に** 1声 (高) に戻すと、4声が「3声→1声」に聞こえる。1音目4声が中途半端だと2音目の1声との段差が出ない。

**矯正のコツ**: 4声で **息を切るほど** 真下まで落とす → そこから 1声 (高平調) を立て直す。落とすときに音節間にわずかな間を空けても良い。

## 5. [[練習プログラム]] (改訂版)

### 優先度1: [[2-1]] と [[1-3]] の声調コンビ集中ドリル

メトロノームで一定リズムを刻みながら以下を反復:
```
2-1: zhi2-bo1 / xian2-jie1 / ti2-gao1 / hang2-tian1 / he2-xin1
1-3: suo1-duan3 / bian1-cheng3 / feng1-xian3 / fen1-jian3 / wu1-ran3
```

- **録音 → 自分の声を再生 → 同じ単語のネイティブ音声と比較**
- 2声の「最後まで上げる」 / 3声の「底まで落とす」 を視覚化 (波形アプリ推奨)

### 優先度2: [[-ian / -eng]] 韻母 と [[guan/dan/lian/zhan]] 音節

- ピンイン単独で全声調を回す: jian1 jian2 jian3 jian4, guan1 guan2 guan3 guan4 …
- ミニマルペア: jian vs jiang, guan vs guang, xian vs xiang (鼻音終わり区別)
- 苦手語の混合練習: 关键 / 监测 / 检测 / 构建 / 风险 / 衔接

### 優先度3: [[4-1]] の振り幅キレ

- 4声を 5→1 まで落とし切ってから1声に入る
- 単語: 聚焦, 滞销, 订单, 化工

### 優先度4: [[3-3]] 変調

- 3-3 → 2-3 ルール: 主板 zhu(3)→zhu(2) ban(3), 扭矩 niu(3)→niu(2) ju(3)
- 「最初の3声を浅くする」感覚

## 8. 方法論注記

- 「success=1」は今回のセッションで「ContextCn / Source Title に "1" (半角・全角)」を全て統合した後の値。
- 「苦手」=  record日付が記録されている&success≠1 と定義。
- Pinyin は `(1)(2)(3)(4)` 表記と声調記号表記 (`ǎ` 等) が混在。両方を正規パースして声調コンビを抽出。
- ベースラインとの比較 (Lift) で「単なる頻度ではなく相対的に苦手」と判定。
- 「巻舌音 zh/ch/sh / 第三声主因 / L/N / ü」は前回の指摘を受けて主軸から外しています。
