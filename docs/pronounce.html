トーン一致度スコア (0-100)

使い方: 単語を選んで ▶ お手本を聞く でTTS音声を確認 → ⏺ 録音 で自分の声を録音 (3秒) → 自動的に あなたの発音 と 理想の声調曲線 が重ねて表示されます。

声調曲線の読み方: 1声=高く平ら / 2声=中→高に上昇 / 3声=低くディップ / 4声=高→低に急下降。
ピンクの理想線にあなたの水色の線が重なるほどスコアが高くなります。
